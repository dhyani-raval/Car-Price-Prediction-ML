# Car Price Prediction Using Machine Learning

## About the Project
A Machine Learning web application that predicts the selling price of a used car based on its details.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Jupyter Notebook

## Features
- Predicts used car selling prices
- Uses a trained Machine Learning model
- Provides a web interface built with Flask

## How to Run
1. Install Python.
2. Install dependencies using `python -m pip install -r requirements.txt`.
3. Run the application using `python main.py`.
4. Open `http://127.0.0.1:5000` in your browser.
